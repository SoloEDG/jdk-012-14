# 余境 · 虚拟艺术馆

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18112 。

## 介绍归属：视线、遮挡与注意停留

靠近不再等同于切换介绍。可见性、归属与交接是三件不同的事：

- 空间层（`src/features/space/lib/visibility.ts`）只回答“看不看得见”：视野角、作品正面朝向、
  中央展台/雕塑遮挡、距离；顺带给出观看一致性得分（视线越居中、越正面、越近越高，
  距离只占一部分权重，所以正面可见的中距离作品能胜过侧后方更近的作品）。
- 作品模块（`src/features/catalog/lib/attention.ts`）决定“谁拥有介绍”：视线持续停留、
  得分过线且未遮挡才建立关注；已选中的作品有滞回优势，两幅相邻作品不会来回闪动。
- 讲解/导览（`src/features/narration/lib/handover.ts`）只在关注真正成立（可见且稳定）时交接。

关键规则：

- 用户主动点击立刻获得介绍，并拥有一段稳定查看期；期间别的作品需要明显更高、更久的注视才谈得上接替，
  保护强度随时间线性衰减，而不是到点突然失效。
- 视线离开就及时交还（约 0.9 秒）；手动选择也最多保留约 1.8 秒。被中央展台遮挡有更长的容忍时间，
  穿过展台不会造成切换。
- 快速转身：当前作品不在视线内时，新作品只需约 0.3 秒确认即可接替，不会一直保留背后的介绍。
- 关注判定跑在固定 100ms 节拍上（不是渲染帧），低帧率只会让采样变稀，不会让计时停摆，
  跨过关注边界也不会漏判。
- 导览到站后才开始讲解；到站后立即转向另一件作品，导览在当前站让位暂停，看回本站即恢复。
  边走边手动选作品会优先于导览。

所有切换、讲解交接、导览动作与每秒观看结算都写入同一份操作记录（localStorage
`yujing-gallery-v1` → `journal`），收藏回顾用同一份记录还原切换次数，并区分：

- 有效观看：作为介绍对象、视线停在作品上的累计时长，≥4 秒计为一次有效观看；
- 短暂路过：只进入过画面、未形成有效观看。

“我的收藏”里可直接展开参观记录，对照切换次数、讲解对象与停留时长。

## 校验

`npm run scenarios` 直接驱动空间层与作品模块的纯函数，覆盖：抖动不闪动、正面较远胜出、
手动查看期、快速转身交还、穿行遮挡、低帧率跨边界、路过不计有效观看，以及讲解/导览交接规则。
